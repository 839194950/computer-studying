## 二、P0 · 学习闭环 ✅ 已于 2026-11-05 完成

> 四项全部落地，测试 71 → 84。实现要点见 `docs/PROGRESS.md` 的「P0 学习闭环」一节。

### 1. 错题本 ✅

**目标**：把错过一次的卡集中起来单独练，让 `lapses` 有出口。

- 新增 `src/lib/stats.ts` → `weakCards(progress, cards)`：筛 `lapses >= 1 && box < 4`，按 `lapses` 降序、`box` 升序排。
- 学习页支持 `/study?mode=weak`：队列直接用这批卡，不走 `buildQueue` 的到期/新卡逻辑。
- 入口两处：首页在"今天没事了"下方显示一张「薄弱 X 张，去练」卡片（仅当 X > 0）；图谱页加一个同名区块。
- 空态：一张都没错过时，首页不显示这张卡（而不是显示 0）。

**验收**：故意答错一张 → 首页出现薄弱卡 → 点进去只有那一张 → 答对两次后从列表消失。

### 2. 自由复习（通关章节可重练） ✅

**目标**：消除"点进去是空的"这个断点。

- `buildQueue` 加 `includeAll?: boolean`：为真时把范围内所有卡都排进队列，忽略 `dueAt`。
- 路由 `/study?chapter=xxx&free=1`。
- 章节空态里加一个次级按钮「这一章都记牢了，再练一遍」，只在 `chapterState === 'done'` 时出现。
- 说明文案要写清楚：提前复习会重排下次到期时间，不是"白练"。

**验收**：把某章刷到 4/4 → 再点进去有空态 → 点「再练一遍」→ 4 张卡依次出现。

### 3. 答错时自动展开详细讲解 ✅

**目标**：错的那一刻给出解释，而不是让人退回去找。

- 反馈阶段的 `<details>` 改成 `open={!isCorrect}` 受控。
- 同时把 `explanation`（一句话）保留在上方，长文在下，层次是"结论 → 原因"。
- 答对时仍收起，避免每次都刷一屏。

**验收**：答错 → 长文自动展开；答对 → 保持收起、可手动展开。

### 4. 键盘操作（桌面） ✅

**目标**：桌面端不摸鼠标也能连续刷完一轮。

- `useEffect` 监听 `keydown`：`1–4` / `A–D` 选答案，`Enter` / `空格` 下一步或提交，`Esc` 退出。
- 选中的选项要有可见的 focus 环（现有 `focus-visible` 已覆盖按钮，补齐即可）。
- 不要在 `<input>`、`<textarea>` 或已展开的 `<details>` 内劫持按键。

**验收**：只用键盘完成一整轮复习。

## 四、P2 · 内容

### 7. 内容审校（建议由你过一遍）

按风险从高到低：

| 位置 | 要核对的点 |
|---|---|
| `hw-binary-03` | 8 位补码 -128 = 1000 0000，取绝对值仍为负 |
| `hw-binary-04` | 常用汉字 UTF-8 = 3 字节，GBK = 2 字节 |
| `sec-tls-02` | TLS 1.3 是 1-RTT，0-RTT 有重放风险 |
| `sec-auth-03` | RBAC 表达不了数据级权限，需叠加 ABAC |
| `hw-network-02` | 视频通话走 UDP 的理由（延迟优先于完整） |
| `os-perm-01` | 目录的 x 权限 = 进入，r = 列出 |

审校只改 `src/content/details/` 与 `src/content/tracks/`，不动代码。

### 8. 内容扩容（可选）

80 → 120 张有两条路，建议先看数据再定：

- **加深**：每条线加一章（如硬件加"存储层级"、安全加"供应链安全"），保持 4 卡/章 → 100 张。
- **加线**：新增「数据库」「前端」两条主线，各 5 章 20 卡 → 120 张。工作量大，要配套两张新章节图。

判断依据：看完 30 天图谱，哪条线的卡最先到期、错误率最高，就先扩哪条。

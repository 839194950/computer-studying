# 记忆芯（Memory Chip）

一个用间隔重复学习计算机知识的网站：每个知识点是一张卡，答对往后推、答错拉回来。React + TypeScript + Vite，学习进度保存在本地浏览器，无账号或后端服务。

## 快速启动

已验证环境：Node.js **v24.13.0**、npm **11.6.2**。使用仓库的 `package-lock.json`，不要在接手时顺带升级依赖。Windows新环境先按 `docs/HANDOFF.md` 设置D盘临时目录与缓存，然后：

```powershell
npm.cmd ci
npm.cmd run dev
```

开发地址以终端实际输出为准。测试与构建：

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e -- --repeat-each=2
```

完整的D盘日志/截图重定向、现有Edge或Playwright Chromium选择方式见交接页。E2E使用独立浏览器上下文与 `127.0.0.1:4178` 专用服务，不复用日常浏览器存档或5173开发服务。不要同时运行两套占用4178端口的E2E。

## 现在能做什么

- 导航：移动端底部栏、桌面端顶部栏（学习 / 地图 / 百科 / 图谱 / 我），选中态带弹簧滑动，学习页不显示导航
- 激励：经验值与等级、每日经验目标、每日任务、7 天打卡日历、连对加分、8 枚成就（全部由现有进度推出，`src/lib/xp.ts` / `achievements.ts`）
- 百科：`/wiki` 全文搜索 100 个条目（标题、讲解、详解都能搜），按主线筛选；条目页可点要点高亮图解、附小测（不计入复习）
- 动效与音效：答对弹跳/答错抖动、底部反馈条滑入、结算纸屑、数字滚动；Web Audio 合成提示音，可在「我」里关闭
- 首页：产品介绍（这是什么 + 三步用法 + 覆盖范围）、今日队列、连胜、掌握度环、五条主线进度
- 学习：**分步图解**（逐步点亮图上的局部 + 一句旁白）→ **详细讲解**（可展开的 2 节长文）→ 单选题 → 反馈；答错当天重排，连错两次放过
- 错题本：答错过且没记牢的卡集中起来单独练（首页 / 图谱都有入口）
- 章节自由复习：通关的章节可以「再练一遍」，不受到期时间限制
- 键盘：桌面端 `1–4` / `A–D` 选择、`Enter` 继续、`Esc` 退出
- 地图：25 个章节路径，前一章全部记牢才解锁下一章；点任一章节直接进入**该章**的队列（4 张），不是全局队列
- 图谱：四色图例、全卡状态、近 30 天掌握度折线、**按主线折叠下钻**（展开看该线 20 张卡的状态与下次复习日）
- 首页五条主线可点进地图
- 设置：每日新卡数、降低动效、导出/导入 JSON、清空
- 存档可靠性：写盘失败（无痕模式、空间满）会在右下角浮出警告，可重试或去导出备份，不再静默丢进度

## 动手实验室

包含位开关与索引查询两项实验，统一主站导航、主题横幅和卡片风格，复用小芯吉祥物；不模拟真实数据库性能。

- 首页「动手实验室」进入 `/labs`；相关章节节点也有独立入口，二进制与索引章节解锁后的导读页同样提供入口。
- 百科与实验双向关联：二进制前三卡、索引四卡可进入对应实验，实验底部提供相关百科卡；编码卡不提供进制实验入口，避免误以为实验支持文本编码。
- `/labs/binary`：8 位开关支持鼠标、触摸和键盘操作，开启位高亮；展示位串、无符号值和二补码，提供 0、127、128、255 预设与重置。
- `/labs/index`：固定 9 条记录，逐步对照顺序扫描和有序索引二分查找的位置、比较次数与结果；支持不存在的键、输入校验和重置，已结束的一侧不再累加比较。
- 实验仅辅助理解，不写学习存档、不发经验、不改变复习或章节解锁；离开页面后重置。索引演示不模拟 B+树或真实查询耗时。

## 内容与图解

- **100 张知识卡**：五条主线 × 5 章 × 4 张。文字参照菜鸟教程的知识分类自行撰写，不复制原文。
- **9 份完整章节导读**：计算机组成、二进制与编码、网络分层、传输与证书、数据库五章。网络导读含3个目标、前置知识与4步案例，复用原TCP封装图；沿用既有解锁规则，编译与解释四卡记牢后可阅读。二进制导读仍须先将计算机组成四卡记牢才能阅读。
- **TLS四卡已审校**：核对八节详解、题解与原图，新增登录页面贯穿导读；澄清握手、0-RTT重放、前向保密、证书身份与CA风险。Web安全前章四卡记牢后可进入导读；阅读和百科小测不写学习存档。
- **网络分层四卡已审校**：核对八节详解、题解与原图，澄清TCP/UDP适用边界、MTU/分片、DNS与HTTP版本差异；不把UDP概括为更快。导读四卡往返、小测与锁定刷新不写存档；一手RFC依据见 `docs/CONTENT_REVIEW.md`。
- **数据库二十卡已审校**：核对40节详解、5份导读与5张概念图，明确PostgreSQL 18示例边界；排序保证、WHERE语境、LEFT JOIN阶段与联合索引跳跃扫描表述已澄清。五章桌面/手机导读闭环及导入拒绝/取消保护验证通过，详见 `docs/CONTENT_REVIEW.md`。
- **二进制四卡已审校**：修正非负数、固定八位补码及 UTF-8 变长边界，一手来源和结论见 `docs/CONTENT_REVIEW.md`。
- **25 张章节概念图**：全部手写 SVG，每章一张总览图，图里有 4 个可聚焦图元，正好对应本章 4 张卡。
- **每张卡 2–4 步图解**：讲解面不再是"一张静态图 + 一句话"，而是逐步把注意力聚到图上的某一块，配一句旁白，走完才进入答题。图按容器宽度自适应放大，标题与标注在手机上也能看清。
- **每张卡 2 节详细讲解**：`src/content/details/` 单独存放，按卡片 id 索引。图解给框架，长文补原理与易错点，讲解面里以折叠面板展开，不打断逐步流程。
- 图元 id 与插画的 `parts` 声明有强校验（`content.test.ts`），写错 focus 测试会直接失败。

## 接手与数据安全

1. 阅读 `docs/HANDOFF.md` → `docs/ROADMAP.md` → `docs/PROGRESS.md` 最后两节；涉及内容时再读 `docs/CONTENT_REVIEW.md` 和对应计划实际记录。
2. 旧机器先在「我」中导出学习存档；新机器/新浏览器用页面导入并确认结果。Git仓库不包含个人学习进度，也没有云同步。
3. 安装锁定依赖，复验单测、构建和E2E，再开始修改。不要把本机D盘历史报告路径当成新环境必备依赖。
4. 保留已有修改、`generated-images/` 与历史证据；不为使测试通过而重置存档规则、删除旧测试或覆盖工作区。

未测范围：真实手机、Safari、Firefox、生产离线，以及真实数据库/TLS协议的性能或互操作。已有jsdom下载导航、Router/减少动效提示及主JS包体积警告留作已知项；详见交接页。

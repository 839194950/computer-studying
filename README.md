# 记忆芯（Memory Chip）

一个用间隔重复把计算机知识真正记住的网站：每个知识点是一张卡，答对往后推、答错拉回来，像背单词那样复习。

## 文档

| 文档 | 作用 | 什么时候看 |
|---|---|---|
| `docs/PROGRESS.md` | 进度日志：每次改动做了什么、为什么这么决定 | 接手时先读「当前状态」和最后两节 |
| `docs/ROADMAP.md` | **剩余**计划与优先级，含已关闭的缺口清单 | 想知道接下来做什么 |
| `docs/superpowers/specs/2026-11-04-memory-chip-design.md` | 原始设计稿（已冻结，仅标注实现差异） | 想了解设计意图与取舍 |
| `docs/superpowers/plans/2026-11-04-memory-chip.md` | 首发实施计划 Task 1–17（已完成，历史存档） | 想看首发是怎么一步步做出来的 |

## 跑起来

```bash
npm install
npm run dev      # 本地开发
npm test         # 单元测试（vitest）
npm run build    # 类型检查 + 生产构建
```

Node 需要 20+（本机验证用 v22.22.2）。若 `node` 不在 PATH 里，按 [Node 官网](https://nodejs.org)的方式安装，或把它的 `bin` 目录加进 PATH 后再执行上面的命令。

## 目录

| 路径 | 职责 |
|---|---|
| `src/app/` | 应用外壳与路由 |
| `src/components/` | 设计系统基件：按钮、卡片、进度环、底部导航（移动）、顶部导航（桌面） |
| `src/illustrations/` | 20 张章节概念图 + 吉祥物小芯（手写 SVG，`base.tsx` 是共用图元） |
| `src/features/` | 页面：home / study / map / stats / settings |
| `src/content/` | 知识卡数据（`tracks/` 放卡片，`details/` 放详细讲解长文） |
| `src/lib/` | 与 UI 无关的算法：时间、间隔重复、统计、队列 |
| `src/store/` | 持久化状态（zustand + IndexedDB） |

## 现在能做什么

- 导航：移动端底部栏、桌面端顶部栏（学习 / 地图 / 百科 / 图谱 / 我），选中态带弹簧滑动，学习页不显示导航
- 激励：经验值与等级、每日经验目标、每日任务、7 天打卡日历、连对加分、8 枚成就（全部由现有进度推出，`src/lib/xp.ts` / `achievements.ts`）
- 百科：`/wiki` 全文搜索 80 个条目（标题、讲解、详解都能搜），按主线筛选；条目页可点要点高亮图解、附小测（不计入复习）
- 动效与音效：答对弹跳/答错抖动、底部反馈条滑入、结算纸屑、数字滚动；Web Audio 合成提示音，可在「我」里关闭
- 首页：产品介绍（这是什么 + 三步用法 + 覆盖范围）、今日队列、连胜、掌握度环、四条主线进度
- 学习：**分步图解**（逐步点亮图上的局部 + 一句旁白）→ **详细讲解**（可展开的 2 节长文）→ 单选题 → 反馈；答错当天重排，连错两次放过
- 错题本：答错过且没记牢的卡集中起来单独练（首页 / 图谱都有入口）
- 章节自由复习：通关的章节可以「再练一遍」，不受到期时间限制
- 键盘：桌面端 `1–4` / `A–D` 选择、`Enter` 继续、`Esc` 退出
- 地图：20 个章节路径，前一章全部记牢才解锁下一章；点任一章节直接进入**该章**的队列（4 张），不是全局队列
- 图谱：四色图例、全卡状态、近 30 天掌握度折线、**按主线折叠下钻**（展开看该线 20 张卡的状态与下次复习日）
- 首页四条主线可点进地图
- 设置：每日新卡数、降低动效、导出/导入 JSON、清空
- 存档可靠性：写盘失败（无痕模式、空间满）会在右下角浮出警告，可重试或去导出备份，不再静默丢进度

## 内容与图解

- **80 张知识卡**：四条主线 × 5 章 × 4 张。文字参照菜鸟教程的知识分类自行撰写，不复制原文。
- **20 张章节概念图**：全部手写 SVG，每章一张总览图，图里有 4 个可聚焦图元，正好对应本章 4 张卡。
- **每张卡 2–4 步图解**：讲解面不再是"一张静态图 + 一句话"，而是逐步把注意力聚到图上的某一块，配一句旁白，走完才进入答题。图按容器宽度自适应放大，标题与标注在手机上也能看清。
- **每张卡 2 节详细讲解**：`src/content/details/` 单独存放，按卡片 id 索引。图解给框架，长文补原理与易错点，讲解面里以折叠面板展开，不打断逐步流程。
- 图元 id 与插画的 `parts` 声明有强校验（`content.test.ts`），写错 focus 测试会直接失败。

## 还没做什么

- 80 张卡的事实准确性还没逐条审校（重点是补码、TLS 握手、RBAC 三处）
- 没有账号与云同步、每日提醒推送（计划在 V2）

## 换环境接手

1. 读 `docs/ROADMAP.md`——看还剩什么、为什么先做那个；
2. 读 `docs/PROGRESS.md` 的「当前状态」与最后两节——看已经做到哪；
3. 读设计文档的「复习机制」「数据模型」两节——理解算法约束；
4. `npm test` 确认基线是绿的（应为 **113 个用例**）。
